## 六、容易踩的坑（SDS 里已写，这里再强调）

### 坑 1：批次四必须逐子元素入场

检查器**从不 hover/click**（`cdp.mjs:237` 只有 `mouseWheel`）。hover 效果得 0 分。必须 13 个元素全部「加载或滚动自动触发」。

### 坑 2：`tiers` 必须在重置前写入

`plot.ts:259` 是 `tiers[k] = 0xff`，在循环**末尾**。照抄「返回 tiers」会拿到全 0xff 的空数组。

### 坑 3：粒子 canvas 定位

`.head` 必须加 `position: relative`。canvas 用 `z-index: 0` + `pointer-events: none`，内容用 `z-index: 1`。**不要用 `z-index: -1`**（会逃逸到 `.wrap`）。

### 坑 4：入场动画的隐藏态

必须写在 `@media (prefers-reduced-motion: no-preference)` **内部**。写在外面再用 transition 撤销，reduced-motion 下内容永久不可见，触发 `reduced-hidden` FAIL（不是 `revealed-text`，那个规则不存在）。

### 坑 5：脏标记的兑现

不能只在「scroll-zoom 归位时」重绘。用户切主题后可能再也不滚回。必须三重兜底：归位 / 2 秒 idle / 下次 repaintAll。

## 八、如果你（实施者）发现 SDS 有错

SDS 经过两轮修订（v1.0 → v2.0 修复 27 项，v2.0 → v2.1 实测校正 5 项）。但仍可能有错。

**遇到 SDS 与代码冲突时**：

1. **以代码为准**，不要为了符合 SDS 而改坏代码
2. 记录冲突（SDS 章节 + 实际代码行号）
3. 按代码的实际情况实施
4. 在提交信息里说明偏离原因

**不要**：为了「符合 SDS」而写出错误的代码。
